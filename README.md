# OOOAI 发卡系统

一个轻量级 PHP 发卡系统空白安装版。仓库只保留商品、卡密、订单、查询和后台管理能力，不包含任何支付接口或真实业务数据。

![OOOAI 发卡系统](logo.png)

## 特性

- 空白安装向导，自动创建数据库表
- 商品管理、上下架、一次性卡密和循环卡密
- 前台提交订单，后台确认后自动发货
- 订单查询页展示已确认订单的卡密
- 响应式前台和后台界面
- 不提交 `config.php`，不包含支付信息

## 环境要求

- PHP 8.0+
- MySQL 5.7+ 或 MariaDB 10.3+
- PHP PDO MySQL 扩展
- Web 服务器：Nginx、Apache 或宝塔 PHP 站点

## 安装

1. 上传源码到站点目录。
2. 创建一个空数据库，或准备有建表权限的数据库账号。
3. 浏览器打开 `install.php`。
4. 填写数据库、后台账号、后台密码和安全码。
5. 安装完成后进入后台添加商品和卡密。
6. 生产环境中删除或限制访问 `install.php`。

## 默认流程

```text
用户选择商品 -> 提交订单 -> 后台确认订单 -> 系统绑定卡密 -> 用户查询订单
```

这个公开版不自动跳转支付，也不会处理支付回调。需要接入支付时，请在私有分支中实现，并确保商户号、密钥、二维码和回调日志不进入公开仓库。

## 安全说明

- `config.php` 已在 `.gitignore` 中排除。
- `pay.php` 和 `notify.php` 是禁用占位文件，防止旧链接继续工作。
- 后台密码和安全码使用 `password_hash` 保存。
- 后台表单带 CSRF 校验。
- SQL 读写使用 PDO 预处理。

## 目录结构

```text
.
├── assets/              # 前端样式和脚本
├── includes/            # 公共函数、认证、CSRF、启动文件
├── storage/logs/        # 运行日志目录，日志不提交
├── admin.php            # 管理后台
├── admin_login.php      # 后台登录
├── index.php            # 前台商品和订单提交
├── install.php          # 安装向导
├── query.php            # 订单查询
├── pay.php              # 禁用的支付占位
└── notify.php           # 禁用的回调占位
```
